klyn

A collection of purely client-side single page apps. See also the GitHub repo.

Gallery

A dynamic image viewer that loads and displays images based on a JSON manifest file. Provides a thumbnail grid view and full-resolution image viewing. Read more…

Usage: gallery.html?from=<url>
Example: view some pretty pics from Half Moon Bay, California in October 2025

JSON Viewer

A client-side JSON viewer that fetches and displays formatted JSON data from URLs. Read more…

Usage: json-viewer.html?from=<url>
Example: view a sample JSON file

Markedup

A client-side markdown viewer that fetches and renders GitHub-flavored markdown files from URLs using marked.js. Read more…

Usage: markedup.html?from=<url>
Example: view markedup.html's own README

WASM Runner

A client-side WebAssembly module runner that executes WASI-compatible WASM modules directly in the browser with support for arguments and STDIN.

Usage: wasm.html?module=<url>&args=<arguments>
Example: run rt_lite version or run a simple calculator

TAP Viewer

A client-side Test Anything Protocol output viewer with color-coded results, summary statistics, and support for subtests and YAML diagnostics.

Usage: tap-viewer.html?from=<url>

Log Viewer

A client-side log file viewer with live search highlighting, pinned multi-pattern filters, thread-id color tinting, and keyboard navigation. Open a local file or fetch one over HTTP.

Usage: log-viewer.html?from=<url>

Flows

A data-driven architecture and call-flow viewer. Pick a flow from the dropdown; the canvas highlights the participating components and draws numbered step badges along the arrows, while the side panel narrates each hop. Flows are authored as JSON (schema included).

Usage: flows/index.html?from=<url>

Bill Splitter

Take a photo of a paper receipt (iPhone camera or desktop file picker), run client-side OCR with Tesseract.js, and split line items among named participants. Tax and tip are distributed proportionally. Everything runs locally — no data leaves the device. Read more…

Usage: bill-splitter/index.html

Googly Eyes

Drop in a photo, detects faces, then draw a pair of googly eyes scaled to each face. Save the result as PNG. Quick and silly; all local, no uploads. Read more…

Usage: googly-eyes/index.html?from=<url>
Example: googlify Einstein

scrollpot

A scroll-driven recipe reader. The sidebar keeps the timers, tools, and ingredients pinned; as you scroll through the steps in the main panel, the items the current step references light up. Multiple concurrent timers survive reloads.

Usage: scrollpot/index.html?recipe=<url>
Example: cook the bundled pancakes sample

These are single-page apps that can be served as static files, with no server-side processing required.
