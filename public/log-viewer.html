Log Viewer

Loading a log

Click the file picker (top right) to open a local file, or append ?from=<url> to the page URL to fetch one over HTTP. The reload button re-reads the current source.

Searching

Type in the search box — matching text highlights live in the visible window. Selecting any text in the log auto-fills the search box. Click filter next to the search box to also hide non-matching lines while you type; click again to go back to highlight-only.

Pinned filters (chips)

Click pin to turn the current search into a persistent chip that stays around as you keep typing. Each chip has three controls:

  • label — click to toggle whether this chip just highlights or also filters (hides non-matching lines). Bold with a solid border when filtering.
  • + — merge the current search text into this chip (the chip's regex becomes old|new). Only shown while the search box has text.
  • × — remove the chip.

Master switch

filters on / filters off (top right) globally enables or bypasses all filter modes. Useful for peeking at the full log without losing your chip setup. Chips in filter mode go dashed and dim when bypassed, so you can still see which ones are set up.

Lines and threads

Click a line to select it (pink). The selected line stays visible even when filtered. If the line starts with a [thread-id]: pattern, sibling lines from the same thread are tinted alongside it.
