jamoji

Type-setting custom emoji "characters" by composing pieces — like Hangul jamo combining into a syllable block. This page is a Phase 1 showcase: a hand-authored exercise of the <jamoji-block> framework before a composer UI is built on top.

The basics

A single emoji renders as itself — sized to 1em, sitting on the text baseline: here is a 🚀 in body copy. Two emojis compose side-by-side: a 🚀🔥 for speed, a 🌙⭐ at dusk, or a ☀️🌧 shifting.

Three emojis form a "main + two modifiers" arrangement (first is the main): 🚀✨💫 or ☁️⚡🌧. Four split into quadrants: 🍕🍔🌮🍦 and 🌸🌺🌻🌹.

Renderers

The default is renderer="auto": Apple platforms (macOS, iOS, iPadOS) use the OS's Apple Color Emoji; everywhere else falls back to Noto Color Emoji SVGs lazy-fetched from jsDelivr. Both renderers can also be selected explicitly.

auto (default) 🚀🔥 🚀✨💫 🍕🍔🌮🍦
renderer="native" 🚀🔥 🚀✨💫 🍕🍔🌮🍦
renderer="noto" 🚀🔥 🚀✨💫 🍕🍔🌮🍦

Named compositions

Register a composition once with jamoji.define(name, …) and reference it by name. The registry carries label, emojis, and layout — the block needs only the name.

  • name="speed" — registered as 🚀💨, labelled "going fast".
  • name="night" — 🌙⭐, "a starry night".
  • name="weather" — ☀️🌧, "shifting weather".
  • name="bloom" — 🌸🌺🌻 in 3t, "three blooms".
  • name="thunder" — ☁️⚡🌧 in 3b, "thunderstorm".
  • name="feast" — 🍕🍔🌮🍦, "a feast".

Accessibility

Each block carries role="img" and an aria-label describing the composed meaning, not the parts. Label precedence is registry → attribute → auto-derived from Unicode names; a multi-emoji block without a meaningful label emits a console warning so authors notice.

Try inspecting these blocks in DevTools to see the resolved aria-label: (registry), 🚀🔥 (attribute), 🚀🔥 (auto + warning in console).

Grapheme integrity

ZWJ sequences like 👨‍🚀 (astronaut) stay intact — they parse as a single grapheme and occupy one cell: 👨‍🚀. Combine an astronaut with fire and you get a 2h composition: 👨‍🚀🔥.

Fallback behaviour

If a Noto SVG is missing or the network fails, the cell silently falls back to native rendering and a one-time console warning is emitted. The block never breaks.
