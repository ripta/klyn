    Using the embed

    A jamoji block is a custom HTML element. To use one on another page, you need two things: the framework module loaded once per page, and the <jamoji-block> markup wherever you want a composed glyph.

    1. Host the framework files

    The framework is four ES modules that must sit next to each other:

    • jamoji.js — entry point
    • registry.js
    • renderer.js
    • unicode-names.js

    Copy all four into a directory on your site (e.g. /assets/jamoji/), or reference this deployment directly.

    2. Load the module on your page

    In <head> or before your first jamoji block:

    <script type="module" src="/assets/jamoji/jamoji.js"></script>

    3. Paste your embed snippet

    The "Copy embed" button gives you something like:

    <jamoji-block layout="2h" label="going fast">🚀🔥</jamoji-block>

    Drop it anywhere in your HTML — inside prose, headings, list items. The block sits inline at the surrounding text's size.

    Optional: named compositions

    If you reuse the same composition across a page, define it once with a name and reference it from markup. Two patterns work:

    Import the define function (recommended):

    <script type="module">
  import { define } from '/assets/jamoji/jamoji.js';

  define('speed', {
    emojis: ['🚀', '🔥'],
    layout: '2h',        // optional — defaults to count-inferred
    label: 'going fast', // optional — used as aria-label
  });
</script>

<jamoji-block name="speed"></jamoji-block>
<p>…and again later: <jamoji-block name="speed"></jamoji-block></p>

    Or use the global, after the module has loaded:

    <script type="module" src="/assets/jamoji/jamoji.js"></script>
<script>
  // jamoji is attached to window after the module evaluates.
  window.addEventListener('load', () => {
    jamoji.define('speed', { emojis: ['🚀', '🔥'], layout: '2h', label: 'going fast' });
  });
</script>

    Notes: definitions live in memory for the current page only — they don't persist or sync across tabs. Define them in a module that loads before (or alongside) the first <jamoji-block name="…"> that uses them. A registered label takes precedence over any label= attribute on the markup.
